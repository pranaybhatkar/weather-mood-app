Mood thresholds (how this is computed)
  1. Windy if wind_kph > 30
  2. Uncomfortable if humidity ≥ 80% OR (temp_c ≥ 28 AND humidity ≥ 70%)
  3. Hot if temp_c ≥ 30
  4. Cold if temp_c ≤ 10
  5. Pleasant otherwise

Evaluated in order; first match wins.
