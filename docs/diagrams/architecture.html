Weather Mood — System Architecture

Static frontend + Vercel serverless proxy + WeatherAPI. The API key lives in server env only — it never ships to the browser. Sources: index.html, app.js, api/weather.js, vercel.json.

Secret boundary. WEATHER_API_KEY exists only in Vercel env + local .env (gitignored). The browser calls the proxy, never WeatherAPI directly in production.
Cache. Proxy sets Cache-Control: s-maxage=300 so repeat city lookups are served from the edge for 5 minutes.
Deploy. Static files + one function, no framework build. Alias: weather-mood-app-theta.vercel.app.
